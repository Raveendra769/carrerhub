# CareerHub

A modern job portal web application built using React, Vite, and Tailwind CSS.

## 🚀 Live Demo

https://carrerhub-dusky.vercel.app

## 📌 Features

- Job listings
- Resume upload
- Modern responsive UI
- Fast Vite build setup
- Tailwind CSS styling

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- TypeScript
- Vercel
